# 8. Glossary

| Term | Definition |
|---|---|
| **Corporate Action** | An official event affecting the underlying stock and therefore the Stock Token, such as a dividend or stock split |
| **Stock Token** | An onchain representation of a stock |
| **Issuer** | The issuer of a Stock Token / the party serving as an official source of corporate-action information |
| **Announcement Date** | The date on which a corporate action is officially announced |
| **Record Date** | The date used to determine who is entitled to the corporate action |
| **Ex-Date** | The date from which the token/stock trades without entitlement to the corporate action |
| **Effective Date** | The date on which the corporate action takes effect |
| **Payment Date** | The date on which a distribution (e.g. a dividend) is actually paid |
| **Ratio** | A conversion ratio, used primarily for stock splits/reverse splits |
| **Normalizer** | The component that standardizes data formats from multiple sources |
| **Verification Layer** | The layer that stores evidence and the validation status of each event |
| **State Machine** | The mechanism that controls event status transitions according to the lifecycle |
| **Onchain Action Engine** | The component that determines and generates instructions for onchain actions |
| **Non-custodial** | A principle under which the system never directly holds or controls user funds |
| **Idempotency** | A property where reprocessing the same input does not produce duplicate effects |
| **Replay Protection** | A mechanism that prevents old instructions from being executed again without authorization |
| **CONFLICTED** | An event status used when conflicting information is found across multiple sources |
